## Question 1

### Which of the following are the three main characteristics of big data that Dr. Sanchez mentions in the videos?

## Question 2

### What does HDFS stand for?

✅ **Answer:** Hadoop Distributed File System

**Explanation:**
HDFS is Hadoop's distributed storage system that stores data across multiple machines in a cluster.

---

## Question 3

### What are the stages of a MapReduce process when working with big data?

✅ **Answer:** input, split, map, sort, reduce

**Explanation:**

MapReduce follows these stages:

```text
Input
 ↓
Split
 ↓
Map
 ↓
Sort/Shuffle
 ↓
Reduce
```

## Question 4

### What does YARN stand for?

✅ **Answer:** Yet Another Resource Negotiator

**Explanation:**
YARN is the Hadoop component responsible for resource management and job scheduling in a cluster.

---

## Question 5

### What is the most accurate definition of Hadoop?

✅ **Answer:** Hadoop is an open-source platform for distributed storage and distributed processing of very large datasets.

**Explanation:**

Hadoop provides:

- Distributed Storage (HDFS)
- Distributed Processing (MapReduce)
- Fault Tolerance
- Scalability

---

## Question 6

### What does MapReduce do?

✅ **Answer:** MapReduce is used to split large amounts of data into smaller chunks for efficient data manipulation.

**Explanation:**

MapReduce:

1. Divides large datasets.
2. Processes the chunks in parallel.
3. Aggregates the results.

This allows Hadoop to process massive datasets efficiently.

---

## Question 7

### Which steps take place between the Map and Reduce tasks?

✅ **Answer:** The Combine function and the Partition function

**Explanation:**

MapReduce pipeline:

```text
Map
 ↓
Combine (Optional)
 ↓
Partition
 ↓
Reduce
```

The Combiner performs local aggregation while the Partitioner organizes data before it reaches the reducers.

---

## Question 8

### What is the function of the Reduce task in MapReduce?

✅ **Answer:** The Reduce task takes the output from the Map as an input, then shuffles and sorts the data into a smaller set of tuples.

**Explanation:**

The Reduce phase:

- Receives mapper output
- Groups similar keys
- Performs aggregation
- Produces the final output

Example:

```text
Input:
<Student A>{1,1}

Output:
<Student A>{2}
```

---

## Question 9

### Which of the following is false about the Combine function in the MapReduce framework?

✅ **Answer:** The Combine function must always be performed in MapReduce.

**Explanation:**

The Combiner is:

- Optional
- Used only when beneficial
- Dependent on the complexity of the data

Its purpose is to reduce the amount of data transferred between mappers and reducers.
