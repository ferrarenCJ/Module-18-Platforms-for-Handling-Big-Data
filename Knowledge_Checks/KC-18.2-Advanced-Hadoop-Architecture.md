# Questions and Answers

## Question 1

### The Hadoop framework is written in which of the following programming languages?

✅ **Answer:** Java

**Explanation:**
Hadoop is an open-source framework developed primarily in Java and uses Java libraries and utilities throughout its ecosystem.

---

## Question 2

### What are the components of the Hadoop architecture?

✅ **Answer:** MapReduce, HDFS, YARN, and Hadoop Common

**Explanation:**

The four primary Hadoop components are:

- HDFS (Storage)
- MapReduce (Processing)
- YARN (Resource Management)
- Hadoop Common (Shared Utilities)

---

## Question 3

### Which of the following are the types of data storage nodes used in the HDFS?

✅ **Answer:** NameNode and DataNode

**Explanation:**

### NameNode

- Master node
- Stores metadata
- Tracks file locations

### DataNode

- Worker node
- Stores actual file blocks
- Handles read/write operations

---

## Question 4

### Which of the following can be used to quickly and easily set up the Hadoop environment?

✅ **Answer:** Docker containers

**Explanation:**

Docker simplifies Hadoop deployment by packaging Hadoop and all required dependencies into a reusable container environment.

Benefits include:

- Easy setup
- Consistent environments
- Simplified testing
- Fast deployment

---

## Question 5

### Which of the following operations are performed by Yet Another Resource Negotiator (YARN)?

✅ **Answer:** Job scheduling and resource management

**Explanation:**

YARN performs two primary functions:

### Job Scheduling

- Breaks large jobs into smaller tasks
- Assigns tasks to cluster nodes

### Resource Management

- Allocates CPU
- Allocates memory
- Manages cluster resources

---

## Question 6

### What is the default replication factor for data files stored in the HDFS?

✅ **Answer:** Three

**Explanation:**

By default, HDFS stores three copies of each data block.

Example:

```text
Block A
├── Copy 1
├── Copy 2
└── Copy 3
```

This replication provides:

- Fault tolerance
- Data availability
- Disaster recovery
