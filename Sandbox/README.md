# Module 18 Sandbox

This sandbox contains temporary files, commands, and test data used while learning Hadoop, HDFS, Docker, and MapReduce.

## Files

### docker-compose.yml

Docker configuration used to start the Hadoop cluster.

### hadoop-lab-notes.md

Reference commands and troubleshooting notes.

### test-data.txt

Small test dataset used for validation.

### wordcount-results.md

Output and observations from Hadoop Word Count testing.

## Purpose

The sandbox provides a safe location to experiment with:

- Docker commands
- Hadoop containers
- HDFS operations
- MapReduce jobs
- Word Count processing
- Hadoop troubleshooting
